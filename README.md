# prediksi_kelulusan_mahasiswa
projek AI untuk memprediksi kelulusan mahasiswa
tujuan proyek untuk memprediksi kelulusan mahasiswa berdasarkan data akademik dan mengklasifikasikan mahasiswa dalam kategori lulus tepat waktu dan tidak lulus tepat waktu
waktu pelatihan 0s 29ms/step
cara keja sistem memasukkan dataset mahasiswa, melakukan preprocessing data, membagi dataset menjadi data training dan testing, melatih model Decision Tree dan ANN, melakukan prediksi kelulusan mahasiswa, mengevaluasi hasil prediksi
cara Menjalankan Program buka Google Colab,  upload file notebook, upload dataset mahasiswa, 
jalankan program Decision Tree, jalankan program ANN, periksa hasil evaluasi masing-masing model,
bandingkan hasil kedua metode
keterbatasan hanya untuk memprediksi kelulusan mahasiswa berdasarkan data akademik dan mengklasifikasikan mahasiswa dalam kategori lulus tepat waktu dan tidak lulus tepat waktu
