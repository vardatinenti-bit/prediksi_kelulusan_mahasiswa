# prediksi_kelulusan_mahasiswa
projek AI untuk memprediksi kelulusan mahasiswa
tujuan proyek untuk memprediksi kelulusan mahasiswa berdasarkan data akademik dan mengklasifikasikan mahasiswa dalam kategori lulus tepat waktu dan tidak lulus tepat waktu
waktu pelatihan 0s 16ms/step
keterbatasan hanya untuk memprediksi kelulusan mahasiswa berdasarkan data akademik dan mengklasifikasikan mahasiswa dalam kategori lulus tepat waktu dan tidak lulus tepat waktu
